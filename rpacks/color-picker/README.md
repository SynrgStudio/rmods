# color-picker

Pick a screen color and copy it to the clipboard.

## Usage

- `color` / `cp` / `picker` / `pick` copies HEX (`#RRGGBB`).
- `color rgb` copies `rgb(r, g, b)`.
- `color hsl` copies `hsl(h, s%, l%)`.
- `color all` copies HEX, RGB, and HSL lines.

After launching, click anywhere on screen to pick the pixel under the cursor. Press Escape to cancel.
